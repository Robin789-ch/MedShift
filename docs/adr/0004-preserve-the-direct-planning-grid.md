# Preserve the direct planning grid

V0.2 retains the full planning-grid workflow for creating Fixed Assignments and Employee Preferences against both Shift Types and departments. React may replace the implementation, but chat does not replace this direct interaction: the grid remains the authoritative way to express precise employee-and-day commitments and preferences, while the agent is limited to the closed scheduling-policy and optimization-objective catalogue. This accepts the cost of two complementary interaction modes in exchange for precision, auditability, and clear ownership.
